ما هو Metasploit؟

Metasploit هو إطار عمل (Framework) لاختبار الاختراق الأخلاقي. يحتوي على أكثر من 2500 ثغرة معروفة، ويساعد الباحثين الأمنيين على اكتشاف الثغرات وإصلاحها قبل أن يستغلها المهاجمون.

المكونات الأساسية

1. Exploit (الاستغلال)

الكود الذي يستغل ثغرة معينة في نظام الضحية.

2. Payload (الحمولة)

الكود الذي ينفذ بعد نجاح الاختراق، مثل فتح باب خلفي (Meterpreter).

3. Auxiliary (المساعدة)

أدوات للمسح وجمع المعلومات (مثل فحص البورتات) بدون اختراق فعلي.

4. Post (ما بعد الاختراق)

أدوات تعمل بعد الدخول للجهاز، مثل سحب الملفات أو تثبيت نفسك.

التشغيل

لتشغيل Metasploit على Kali Linux:

msfconsole

أوامر أساسية

بعد الدخول إلى Metasploit، استخدم الأوامر التالية:

help                  # عرض المساعدة
search eternalblue    # البحث عن ثغرة معينة
info exploit/windows/smb/ms17_010_eternalblue   # معلومات عن ثغرة
use exploit/windows/smb/ms17_010_eternalblue    # اختيار ثغرة
show options          # عرض الإعدادات المطلوبة
set RHOSTS 192.168.1.1  # تحديد الهدف
run                   # تشغيل الاستغلال
exit                  # الخروج

مثال: فحص شبكة

لاستخدام Metasploit في فحص الشبكة (Auxiliary Module):

use auxiliary/scanner/portscan/tcp
show options
set RHOSTS 192.168.1.0/24
set PORTS 1-1000
run
⚠️ تنبيه مهم: استخدم Metasploit فقط على الشبكات والأجهزة التي تملكها أو لديك إذن كتابي باختبارها. الاستخدام غير القانوني يعرضك للمساءلة القانونية.

قوة Metasploit الحقيقية

Metasploit هو الأداة الأساسية في أي فريق Red Team. يستخدمه المحترفون في:

  • اختبار اختراق الشبكات
  • اكتشاف الثغرات في التطبيقات
  • محاكاة هجمات حقيقية
  • التدريب في بيئات معزولة (Labs)
