🐉 أدوات Kali Linux

👑 TEAM AL-HAKIM
⚠️ هذا المحتوى تعليمي فقط. استخدام الأدوات ضد أنظمة بدون إذن غير قانوني.

1. Nmap - فحص الشبكات

أداة فحص الشبكات والمنافذ. تستخدم لاكتشاف الأجهزة المتصلة والخدمات المفتوحة.

nmap -sV 192.168.1.1
nmap -sn 192.168.1.0/24
nmap -A 192.168.1.1

2. Hydra - تخمين كلمات المرور

أداة قوية لتخمين كلمات المرور على خدمات مختلفة مثل SSH و FTP و HTTP.

hydra -l admin -P passwords.txt ssh://192.168.1.1

3. Sqlmap - فحص SQL Injection

أداة لاكتشاف واستغلال ثغرات SQL Injection في تطبيقات الويب.

sqlmap -u "http://example.com/page?id=1" --dbs

4. Burp Suite - تحليل الويب

أداة لتحليل أمان تطبيقات الويب واعتراض الطلبات.

5. Wireshark - تحليل الشبكة

أداة لتحليل حركة الشبكة والتقاط الحزم.

wireshark
